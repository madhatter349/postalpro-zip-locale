03 / ENDPOINTS

Every route. Zero friction.

Base URL — https://madhatter349.github.io/postalpro-zip-locale

GET /data/zip_locale_detail.json Full dataset +

Every ZIP locale record in a single JSON array (~15 MB). Prefer a state file or the explorer.

JavaScript 
fetch('…/data/zip_locale_detail.json')
  .then(r => r.json())
  .then(data => console.log(data.length, 'records'))
GET /data/states/{CODE}.json By state / territory +

All records for one state, territory, or district. Uppercase 2-letter code (CA, PR, DC…).

Python 
import requests

data = requests.get(
    '…/data/states/NY.json'
).json()

for record in data[:5]:
    print(record['delivery_zipcode'], record['locale_name'])
GET /data/index.json Coverage & freshness +

Lightweight index: every area code, its record count, kind (state / district / territory / federated), and freshness timestamps.

cURL 
# states + counts + kinds + freshness
{
  "state_count": 59,
  "state_breakdown": { "states": 50, "district": 1, "territories": 5, "federated": 3 },
  "states": [ … ]
}
GET /data/last_updated.txt USPS publish date +

Date USPS last published a new dataset version. /data/last_checked.txt is the last verification time.

JavaScript 
fetch('…/data/last_updated.txt')
  .then(r => r.text())
  .then(date => console.log('Last updated:', date))
GET /data/last_checked.txt Mirror health +

ISO timestamp of the last successful verification run. The daily workflow writes a heartbeat here so the mirror provably stays fresh.

cURL 
# e.g.
2026-08-25T10:11:57.234Z
GET /data/health.json Run status +

Result of the most recent update run. status flips to error if a scheduled run fails, so consumers can detect stale data programmatically.

cURL 
{ "status": "ok", "result": "updated" }
GET /data/changes.json Latest diff +

Records added, removed, or changed between the previous and current USPS publishes — perfect for incremental sync instead of re-downloading 15 MB.

JavaScript 
fetch('…/data/changes.json')
  .then(r => r.json())
  .then(c => c.added + ' new, ' + c.removed + ' removed')
GET /data/history.json Update history +

One entry per data-updating run (up to 400) with totals and diff counts — a machine-readable release history of the dataset.

cURL 
# latest entry
fetch('…/data/history.json').then(r => r.json()).then(h => h.at(-1))
GET /data/schema.json · /openapi.json Machine-readable specs +

JSON Schema (2020-12) for every artifact, plus an OpenAPI 3.1 description of this API for codegen, validation, and docs tooling.

cURL 
# validate with ajv, generate clients, render docs
ajv compile -s …/data/schema.json
GET /data/csv/zip_locale_detail.csv CSV (full + per state) +

RFC 4180 CSV with a header row. Per-state files live at /data/csv/{CODE}.csv (e.g. /data/csv/NY.csv).

Python 
import pandas as pd

df = pd.read_csv('…/data/csv/NY.csv')
print(df.head())
GET /data/zip_locale_detail.sqlite SQLite database +

One file, full SQL. The records table is indexed on ZIP, state, and locale; a meta table carries provenance.

SQL 
-- download first, then query locally
SELECT physical_city, COUNT(*) AS n
FROM records
WHERE delivery_zipcode LIKE '100%'
GROUP BY physical_city
ORDER BY n DESC
LIMIT 10;
