# Endpoints

Base URL — https://madhatter349.github.io/postalpro-zip-locale
GET /data/zip_locale_detail.json Full dataset +

Every ZIP locale record in a single JSON array (~15 MB). Prefer a state file or the explorer for most use cases.

JavaScript 
fetch('…/data/zip_locale_detail.json')
  .then(r => r.json())
  .then(data => console.log(data.length, 'records'))
GET /data/states/{STATE}.json Filter by state +

All records for one state. Use the 2-letter uppercase abbreviation (CA, NY, TX…).

Python 
import requests

data = requests.get(
    '…/data/states/NY.json'
).json()

for record in data[:5]:
    print(record['delivery_zipcode'], record['locale_name'])
GET /data/index.json States & freshness +

Lightweight index: state codes, record counts, and last-updated/verified timestamps. Use this to discover available states without downloading the full dataset.

Response 
{
  "total_records": 44339,
  "state_count": 59,
  "last_updated": "July 01, 2026",
  "states": [ { "state": "AK", "count": 281 }, … ]
}
GET /data/last_updated.txt USPS publish date +

Date USPS last published a new version of the dataset. Plain text. /data/last_checked.txt is the ISO timestamp the mirror last verified the source.

JavaScript 
fetch('…/data/last_updated.txt')
  .then(r => r.text())
  .then(date => console.log('Last updated:', date))
