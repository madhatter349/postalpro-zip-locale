03 / ENDPOINTS

Five routes. Zero friction.

Base URL — https://madhatter349.github.io/postalpro-zip-locale

GET /data/zip_locale_detail.json Full dataset +

Every ZIP locale record in a single JSON array (~15 MB). Prefer a state file or the explorer.

JavaScript 
fetch('…/data/zip_locale_detail.json')
  .then(r => r.json())
  .then(data => console.log(data.length, 'records'))
GET /data/states/{STATE}.json Filter by state +

All records for one state. Uppercase 2-letter code (CA, NY…).

Python 
import requests

data = requests.get(
    '…/data/states/NY.json'
).json()

for record in data[:5]:
    print(record['delivery_zipcode'], record['locale_name'])
GET /data/index.json States & freshness +

Lightweight index: state codes, record counts, and freshness timestamps. Discover available states without the full download.

cURL 
# states + counts + last_checked
{
  "state_count": 59,
  "last_updated": "July 01, 2026",
  "states": [ … ]
}
GET /data/last_updated.txt USPS publish date +

Date USPS last published a new dataset version. /data/last_checked.txt is the last verification time.

JavaScript 
fetch('…/data/last_updated.txt')
  .then(r => r.text())
  .then(date => console.log('Last updated:', date))
GET /data/last_checked.txt Mirror health +

ISO timestamp of the last successful verification run. The daily workflow writes a heartbeat here so the mirror provably stays fresh.

cURL 
# e.g.
2026-08-25T10:11:57.234Z
